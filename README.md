## 👨‍💻 Sobre mim

Desenvolvedor full-stack com experiência em TI corporativa e em projetos web de ponta a ponta, do banco de dados ao front-end.

- Como **Analista de TI**, sustentei o ERP TOTVS WinThor e desenvolvi aplicações internas em **React** e **Node.js** integradas a bancos **Oracle** e **MySQL**.
- Em projetos próprios, trabalho com **Next.js**, **TypeScript** e **Supabase**, com validação de dados, testes automatizados e integração contínua.
- Formação full-stack de **1.500 horas pela Trybe** e graduação em **Engenharia de Computação na UFC** em andamento.

📫 Aberto a oportunidades como desenvolvedor e a projetos freelance.

## 🚀 Projetos em destaque

### 💰 [MyFinPocket](https://github.com/devpedroeduardo/my-finpocket)
Aplicação de finanças pessoais (PWA instalável) para registrar receitas e despesas.
- **Stack:** Next.js, React, TypeScript, Tailwind CSS, Supabase, Zod
- **Segurança:** Row Level Security (RLS) no Supabase e proteção de rotas via middleware
- **Qualidade:** testes com Jest e testes E2E com Playwright rodando no GitHub Actions a cada push

### 📋 [Bemobile — Desafio técnico front-end](https://github.com/devpedroeduardo/bemobile-project)
Tabela de dados interativa e responsiva, com busca em tempo real e componente acordeão próprio, sem bibliotecas externas.
- **Stack:** React, Vite, Styled-Components, json-server
